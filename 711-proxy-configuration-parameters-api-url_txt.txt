## API URL In proxy configuration with API, the "Get API URL" module is the final and essential step in configuring your proxies, which shows as a URL. You may specify the number of proxies that you wish to see or export, and customize your URL by choosing the format, separator that best suits your needs.
You can directly obtain proxy IP addresses via API interface, or you may open the URL, copy the proxy list in "host:port" format to your clipboard to use.
